APP NAME: AO3 Reader

ONE-LINE PITCH: You can read AO3 fics offline on a dedicated app so it saves everything you've read and all the features from the original website. All features will be added later.

WHO IS THIS FOR?: (describe your target user — age, interests, what they struggle with) Target users are people who use AO3. They might struggle with not having wifi connection/cellular data, disliking the web format, layout of the original website being confusing, e.t.c.

THE PROBLEM: It solves the problem of there not being an AO3 app. People would download it because they would appreciate having an app to read AO3 on. One of the problems of not having an app is that there is a screen time limit on Safari on my phone. That one was a joke, don't read too much into it. Another reason that there should be an app is because on the website, unless you keep all your tabs open, you will lose your place in a fic if you reload. Also, there's the issue of keeping many tabs open because you are reading so many stories.

CORE FEATURES (MVP — version 1.0):
1. Offline reading
2. Customizable U.I. (e.g. changing font, font size, background color, e.t.c.)
3. Easier organization (bookmarks, marked for later, e.t.c.)
4. Quick guides to understand how to use AO3 and features

NICE-TO-HAVE (version 2.0 — later):
1. Logging into your AO3 account besides just accessing a fic
2. Push notifications?

HOW AI IS USED: You can use AI to help you search for specific fics you want, it would be a bit difficult to implement though.... When I say, use AI to help you search for specific fics, I mean that it looks through the fic and finds more fics similar to that based on what you say you liked about the fic.

ONE SCREEN DESCRIPTION: They see their profile screen, which either shows guest or their own profile. Underneath that it says what stories you have read recently and ones you yourself have written. There is also a notifications section with stuff like if a story got updated, comments, etc.

SUCCESS = people coming back to use it and read every day!
